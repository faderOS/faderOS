# Configuration examples

`link-settings.conf` is a v3 example with DHCP enabled, OBS selected, loopback
mixer endpoints, and the other two server profiles disabled. Network addresses
use the documentation-only 192.0.2.0/24 range. Copy it to a working directory and
edit through the web/panel before connecting to a real mixer.

`obs-mappings.json` demonstrates named scenes and transitions. Replace the names
with your OBS configuration. Neither file contains credentials or calibration.
